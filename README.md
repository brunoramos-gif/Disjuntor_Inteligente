# Disjuntor Inteligente

Projeto de disjuntor inteligente baseado em ESP32 utilizando PlatformIO.

## Descrição
Sistema embarcado para monitoramento e controle de disjuntor inteligente, permitindo integração entre hardware e firmware.

## Hardware
- ESP32
- Relés / acionamento
- Sensores (se aplicável)
- PCB desenvolvida em KiCad

## Software
- PlatformIO
- C/C++
- Firmware embarcado

## Estrutura do Projeto
src/ -> código principal
include/ -> headers
lib/ -> bibliotecas
test/ -> testes

## Como compilar
```bash
pio run
